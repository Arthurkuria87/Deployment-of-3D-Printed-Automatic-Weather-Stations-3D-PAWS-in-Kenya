# 3DPAWS Validation Toolkit

A Python toolkit for processing, validating, and comparing 3DPAWS Automatic Weather Station observations against Kenya Meteorological Department (KMD) observations.

## Features

- Import raw CHORDS data
- Data quality control
- Sensor validation
- Daily aggregation
- Statistical comparison
- Automatic plots
- Validation reports
